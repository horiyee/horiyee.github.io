# horiyee.github.io

| Directory | Role |
| --- | --- |
| `client/` | Portfolio site (GitHub Pages) |
| `blog/` | Blog foundation for `blog.horiy.dev` |

## Checks

Each package supports:

```bash
pnpm typecheck
pnpm check
pnpm test
pnpm build
```

CI runs these for `client/` and `blog/` on push and pull requests.
